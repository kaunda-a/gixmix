## What You Can Do

The [GixMix Text Case Converter](/tools/text-converter) supports 10 different case types:

### Common Cases
- **UPPER CASE** — Headlines, emphasis, acronyms
- **lower case** — URLs, usernames, casual writing
- **Title Case** — Blog posts, article titles, headings
- **Sentence case** — Normal writing, emails

### Developer Cases
- **camelCase** — JavaScript variables (myVarName)
- **PascalCase** — Class names, React components (MyComponent)
- **snake_case** — Python, database fields (my_field_name)
- **kebab-case** — URLs, CSS classes (my-class-name)

### Fun Cases
- **aLtErNaTiNg** — For when you want to look sarcastic on the internet
- **iNVERSE cASE** — The opposite of whatever you typed
